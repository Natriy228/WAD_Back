#Лабораторная работа №3

Методы:
	GET /waves - Получение всех диапазонов для плитки. Возможен фильтр по значению reqFreq (диапазоны, в которые входит)
	POST /waves - Создание черновика нового диапазона
	GET /waves/{id} - Получение карточки конкретного диапазона. С помощью атрибута next возможно получение следующей карточки
	DELETE /waves/{id} - Мягкое удаление карточки по ID
	POST /waves/draft/image - Добавление картинки и видео созданному черновику
	POST /waves/{id}/like - В зависимоти от параметра isLike установка или снятие лайка
	GET /waves/draft - Получение данных о черновике текущего пользователя
	PUT /waves/draft/publish - Публикация черновика текущего пользователя
	POST /user/register - Регистрация нового пользователя
	POST /user/auth - Вход в систему с логином login и паролем password
	POST /user/deauth - Выход из системы

Таблицы:
	waves - содержит информацию о всех диапазонах
		id (int) - идентификатор
		status (string) - статус (ОК / Черновик / Удалён)
		name (string) - название
		desc (string) - описание
		lowWave (float) - нижняя граница диапазона
		highWave (float) - верхняя граница диапазона
		img (string) - ссылка на картинку
		video (string) - ссылка на видео
		cDate (date) - дата создания
		dDate (date) - дата мягкого удаления
		ownerId (int) - ID пользователя-владельца
		
	users - содержит информацию о всех пользователях
		id (int) - идентификатор
		nickName (string) - имя пользователя, по совместительству логин
		password (string) - пароль
		role (string) - роль (пользователь / администратор)
		
	likes - содержит информацию о лайках
		id (int) - идентификатор
		waveId (int) - идентификатор диапапзона
		userId (int) - идентификатор пользователя
